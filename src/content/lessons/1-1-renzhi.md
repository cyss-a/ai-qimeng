很多同事对人工智能（AI，Artificial Intelligence）又期待又害怕，往往是因为把它想得太神，也太吓人。这一讲不聊原理，只帮你建立一句话的判断力：**它最擅长"有明确输入、要稳定输出"的活；它不擅长"要拍板、要担责、要临场应变"的活。**

先说清一个容易混淆的点：你现在天天听到的"大模型"，通常指的是大语言模型（LLM，Large Language Model），也就是能理解和生成文字的那类模型；而"生成式 AI（Generative AI，能凭空产出文字、图片、视频的 AI）"是更大的帽子，文字只是其中一种。这一讲不抠定义，你只要记住：咱们职场里天天使的，基本都是"生成文字"的这类大模型。

## 它现在最擅长的事

为什么这些活它做得好？因为它们有个共同点——规则清楚、输入明确、对错相对好判断。模型只要照着"接下来最可能的文字"往下接，就能稳定产出。把日常办公里那些"规则清楚、重复出现"的任务交给它，通常马上就能见效：

- **改写与润色**：把口语改成得体的邮件、把啰嗦的段落压成三点、把中文摘要成英文。比如你刚跟客户电话完，脑子里一堆碎话，丢给它"整理成给老板的 3 条要点"，比你自己对着空白页憋快得多。
- **从杂乱到结构**：把一段会议记录整理成"结论 / 待办 / 责任人 / 时间"的表格。你不用再手动分列，它一下就排好了。
- **按模板生成初稿**：周报、通知、提纲、问卷、话术，给它格式它就能填。你提供骨架，它填血肉。
- **解释与翻译**：把看不懂的术语、报错、合同条款，用大白话讲一遍。它像个随叫随到的百科同事。

> 关键不是"让它替你思考"，而是"让它替你把已经想清楚的事，做得更快、更整齐"。判断"该写什么"的仍然是你，它负责"写得又快又顺"。

## 它现在做不好的事

下面这些别硬塞给它，容易翻车。新手最爱踩的坑，就是分不清"它写得好"和"它对"。

- **替你做重要决定**：要不要涨薪、选哪份方案、是否签约——它给的是"看起来合理的建议"，不是责任。它不知道你的处境全貌，给的选项往往"政治正确但没用"。
- **处理你不确定的事实**：它会一本正经地编内容（行业里叫"幻觉"，Hallucination，模型一本正经地编内容）。涉及人名、数字、法规、引用，必须你本人核对。常见翻车：让它"查一下某政策的条文编号"，它能编出一个看着很真的编号，实则根本不存在。
- **替你背锅**：对外发出的东西，署名的是你，责任也是你的。模板套得再漂亮，错别字、错数据、不对口的语气，最后都是你扛。

## 一个判断小口诀：交出去，还是留给你

为什么这么分？因为模型本质是"顺着概率接话茬"，它擅长"大概率对"的套路活，不擅长"没有标准答案、要担后果"的判断活。每次想把活交给 AI，先在心里过一遍这张表：

| 这类活 | 交给 AI | 留给你 |
| --- | --- | --- |
| 有模板、要整齐 | ✓ |  |
| 要拍板、要担责 |  | ✓ |
| 要查证的事实 | 先帮你找，你核对 | ✓ |
| 重复、费时间 | ✓ |  |

简单说：**"体力活"交给它，"判断活"留给你。** 这里的"体力活"不是搬砖，而是指那些不怎么动脑、但要花时间的整理、改写、排版；"判断活"是指拍板、担责、跟人打交道、拿主意。新手最容易犯的错，是把"判断活"也甩出去——比如让 AI 决定"这个客户该不该给折扣"，它给的数字听起来有道理，但既不了解你的利润底线，也不承担丢单的锅。

## 常见疑问：那它到底能不能帮我"想创意"？

能，但要换个用法。别让它"替你想"，而是让它当"灵感垫脚石"：你先有个模糊方向，让它列 5 个角度、挑刺、做反面论证。它给的未必都对，但能逼你想得更全。记住，最后的取舍权在你。

## 三个真实场景：看清它帮在哪、坑在哪

光讲原则有点虚，看三个具体情形，体会"体力活交给它、判断活留给你"到底怎么落：

- **场景一：30 分钟会议，5 分钟出纪要。** 把语音转文字后的稿子丢给它，说"整理成：结论 / 待办 / 负责人 / 截止时间 四列表格，只忠实整理"。你省下的是逐句听、逐行归的时间；"这场会到底重不重要"的判断，仍归你。
- **场景二：客户一段长语音的抱怨，提炼成可行动的回复。** 转文字后让它"列出对方三个核心诉求，并给出我该回应的要点"。它列得对不对，取决于你给的文字全不全——原话漏了，它就编。
- **场景三：英文产品文档，压成给老板的一页中文。** 它翻译和压缩都快，但文档里的关键数字、型号，发出前你必须自己对着原文核一遍：翻译流畅不等于翻译准确。

一个好用的类比：把它当成一名**不会累、但没常识的实习生**。你交代清楚"给谁、要什么、别碰什么"，它执行力惊人；你只说"你看着办"，它就给你一堆"看着对、实际偏"的东西。带新人的经验，在这儿完全用得上。

## 今天就能试的一件事

打开你常用的聊天助手，把今天最烦的一件小活丢给它。比如整理一段聊天记录、把一段中文改成邮件语气。先不求完美，体会一下"它快在哪、你还要补什么"。新手常犯的错是：一上来就让它"写一份完美方案"，结果大失所望。正确姿势是先拿低风险的碎活练手，建立手感。

## 小结

- 人工智能（AI）是大概念；职场里你用的基本是大语言模型（LLM）这类生成式 AI。
- AI 擅长"有明确输入、稳定输出"的重复活，不擅长"要拍板、要担责"的判断活。
- 对外发出的内容，你本人要核对一遍；事实类信息必须自己查证，警惕幻觉。
