很多人一听 GitHub，第一反应是"那是程序员用的，我不懂代码用不了"。这一讲先把这件事掰正：**GitHub 不是程序员的专利，它是普通人也能直接受益的巨型资产库。**

## 一句话理解 GitHub

你可以把它粗暴地理解成"全世界开发者的朋友圈 + 网盘"。来自世界各地的开发者，把自己的软件、代码、资料都放在这里。你不仅能下载来用，还能在别人的基础上继续修改、完善，甚至参与一起开发。

它的核心精神就四个字：**开源共创**。

## 第一步：注册登录

来到 GitHub 主页，点右上角的 Sign up（注册），填邮箱、密码、用户名就行。

只有一个小坑提醒你：**注册时那一排推广邮件的勾选，记得取消掉**。不然接下来一段时间，你的邮箱会被各种产品动态塞满。

## 第二步：全英文界面别慌

很多人一进来看到满屏英文，转身就想走。别走，两招解决：

- **浏览器自带翻译**：Chrome 右键"翻译成中文"即可，界面立刻变中文主场。
- **GitHub 中文化脚本**：装一个浏览器插件，能把界面长期中文化。

不过这一讲我建议你**先用英文界面跟着学一遍**。因为那些核心按钮的名称是固定的（Code、Issues、Pull requests、Fork、Star……），你记的是名字本身。不管翻不翻译，日后用起来都不受影响。

## 普通人怎么"逛"GitHub：找资源的 5 种方法

程序员逛 GitHub 是去提交代码，我们普通人逛，目的是**找到能用的好东西**。先判断一件事：你心里有没有明确目标？

### 方法一：搜索栏直接搜关键词

目标明确时，直接在顶部搜索栏输入关键词。比如想找一个 PDF 工具，就搜 `PDF`。

这里送你两个特别好用的关键词：

- **`Free`**：筛选免费资源。
- **`Awesome`**：这是开源圈一个约定俗成的词，意思是" Awesome 列表"——开发者把某一领域的优质资源整理成一个清单。比如搜 `Awesome` 加上你的领域，会冒出来一堆别人替你筛过一轮的合集，不用自己大海捞针。

### 方法二：让 AI 帮你找

有时候你只知道"我想要这个功能"，但根本不知道它叫什么、有哪些工具。这种模糊需求，直接丢给 AI。

比如你说："帮我找几个 GitHub 上可以本地运行、适合 Windows、小白能直接用的开源语音转文字工具。" AI 会根据你的条件，列出一份带名字和特点的菜单，比你瞎搜准得多。

### 方法三：Explore / Trending 逛趋势

一点想法都没有、纯闲逛时，点左上角侧边栏的 Explore（探索），进去能看到 Trending（趋势榜）。这里汇集了全球开发者最近涌现出来的开源项目，可以按今天、本周、本月筛选，也能切换成中文，专门找国内开发者做的项目。

AI 领域更新极快，很多突然冒头的新工具，你都能在这里第一时间发现。

### 方法四：用 Star 当书签

项目一多，怎么判断好坏？最直观的标准就是 **Star（星标）**——你可以理解为"代码界的点赞 + 收藏"。

- 点开任意项目，右上角那个数字就是它的 Star 数。
- **100 以上**基本算靠谱；**1 万以上**基本是这个领域的顶流了。
- 遇到喜欢的项目，顺手点个 Star，它会收进你个人主页。以后点开头像找 Star 列表，宝藏项目随时能找回。

### 方法五：其他社区和自媒体

除了 GitHub 站内搜索，很多技术社区、自媒体也会持续整理优质开源项目合集。把这些入口搭配起来用，日常找资源绝对够用。

## 进阶：搜得更准、挑得更稳

### 搜索语法：给关键词加"过滤器"

只搜一个词，结果往往几千上万条，根本看不过来。在搜索栏里加上下面这些"限定符"，立刻精准：

- `stars:>1000`：只看 Star 超过 1000 的项目，自动过滤掉无人问津的。
- `language:Python`：只看某一门语言写的（换成 `JavaScript`、`Go` 等都行）。
- `pushed:>2025-01-01`：只看这个日期之后还有更新的，专治"僵尸项目"。

举例：想找近期活跃的 Python 翻译工具，就搜 `translate stars:>500 language:Python pushed:>2025-01-01`。

### 挑项目：先确认它"还活着"

前面讲了用 Star 判断好坏，但 Star 高不等于项目没凉。下载前一定再扫一眼：

- 进项目主页，看文件列表上方的 **last commit**（最近提交）——显示"3 years ago"就要警惕。
- 点开 **Insights** 里的 **Commits**，看提交是不是长期有规律，而不是某一年突然断了。

一个还在持续更新的项目，才值得你花时间下载、学习、甚至参与。

## 本讲到这里

先建立两个认知：

- **GitHub = 资产库**，普通人也能直接下载、使用、学习别人的成果。
- **找资源有套路**：明确目标就搜 `Free`/`Awesome`；模糊需求让 AI 帮找；闲逛看 Trending；用 Star 判断质量并当书签。
