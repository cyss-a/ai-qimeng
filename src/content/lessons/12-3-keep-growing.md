搭起来容易，坚持用、用出效果难。这一讲把踩过的坑和一套能落地的起步节奏给你，照着走，它才不会又变成吃灰的收藏夹。

## 四个避坑提醒

**第一，不要一开始就追求全自动。** 先跑通最小闭环（收集 → 消化 → 沉淀 → 输出），再让成果回流。一上来就想"全自动化"，多半会因为规则没打磨好，产出一堆垃圾，然后你就不想用了。

**第二，不要把文件夹设计得太复杂。** 四层就够：`01原料库`（网页、论文、截图、视频字幕、会议纪要）、`02概念库`（长期有用的内容）、`03_Skill库`（可复用的方法，比如选题判断、文风、周报、分析框架）、`04输出库`（文章、报告、方案、PPT、视频脚本）。再多就维护不动了。

**第三，一定要写知识库规则说明（AGENTS.md）。** 没有规则，AI 不知道你想要什么格式、什么标准，知识库迟早退化成新的信息垃圾场。这条是前面反复强调的命门。

**第四，不要把敏感信息放进自动处理目录。** API Key、密码、客户隐私，千万别丢进会被 AI 自动读取的文件夹。本地知识库也要讲安全。

## 四周起步计划

别想一步到位，四周就能从 0 到"长起来"：

- **第 1 周**：搭好 Vault，写好 AGENTS.md，让 AI 做第一次消化。目标是感受"它真的帮你整理了"。
- **第 2 周**：沉淀 3 个 Skill。从选题判断、文风、周报、分析框架里挑你最常用的三个，写成可复用的方法草稿。
- **第 3 周**：把输出回流。你每次产出的文章、报告、PPT，丢进 `04输出库`，让 AI 定期复盘、重新喂回知识库。这一步最关键——过去的产出开始参与未来的产出。
- **第 4 周**：做一次知识库体检，看看哪些规则不好用，优化一下 AGENTS.md。

## 自生长循环：它为什么会"自己长"

把上面串起来，就是一个闭环：

> 原料输入（网页 / 论文 / 会议纪要）→ AI 消化整理（提炼、打标签、建链接）→ 方法论沉淀（可复用的 Skill）→ 输出回流（产出再喂回去）

这个循环一旦跑通，知识库就不再依赖你手动维护，而是自己会生长、迭代、产出。你喂得越多，它越懂你；它越懂你，你产出越快；产出又快反哺进去——正向飞轮转起来。

## 小结

- 四避坑：别一上来全自动、别把目录搞复杂、一定要写 AGENTS.md、敏感信息别进自动目录。
- 四周节奏：搭库消化 → 沉淀 Skill → 输出回流 → 体检优化。
- 自生长循环：原料 → 消化 → 沉淀 → 回流，正向飞轮。
- 一句话记住：重点不是笔记更多，是让过去的积累参与未来的输出。
