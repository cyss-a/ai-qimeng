# WorkBuddy 阅读与学习指南：从入门到团队落地

这是一条面向新手、任务实践者和团队负责人的 WorkBuddy 学习路线。你不必从头背功能：先找到当前最接近的工作问题，完成一项真实任务，再沿着使用手册、实战案例、进阶系统和团队落地逐步深入。

## WorkBuddy 新手入门路线

从[第一篇：先把 WorkBuddy 用起来](/ai-qimeng/workbuddy/bluebook/part1/)开始，依次完成：

1. 下载、安装和登录。
2. 认识主界面、任务与工作区。
3. 完成第一个可检查的任务。
4. 加载一个真正用得上的 Skill。
5. 再学习连接器、外部 API 与自动化任务。

建议边读边做，不要只浏览截图。每完成一章，至少留下一个可复用的提示词、模板或操作记录。

## 按真实任务选择 WorkBuddy 教程

直接进入[第二篇：案例篇](/ai-qimeng/workbuddy/bluebook/part2/)，按问题选择章节：

- 处理 Word、Excel、PPT：第 11 章。
- 整理电脑文件：第 12 章。
- 远程控制电脑：第 13 章。
- 资讯、收藏、会议和投资：第 15～18 章。
- AI 视频、自媒体和 GEO：第 19～21 章。

案例跑通后，再回到第三篇，把你的做法整理为 Skill、自动化或多 Agent 系统。

## WorkBuddy 团队落地路线

重点阅读[第三篇：进阶篇](/ai-qimeng/workbuddy/bluebook/part3/)与[第四篇：岗位与行业落地](/ai-qimeng/workbuddy/bluebook/part4/)。

团队实践建议同时记录：

- 输入资料和权限边界。
- 任务拆解方式和失败回退。
- 交付物的验收标准。
- 可以复用的 Skill、模板和自动化。
- 哪些步骤必须由人确认。
